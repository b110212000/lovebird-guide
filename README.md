# 香蕉的养鸟手册 v2.2.0

基于 iPhone PWA 的精简 App 介面。
首页只显示欢迎、今日进度、喂食检查和打卡/指南捷径。左上角为菜单，底部五项：首页、指南、月龄、打卡、设置。
设置按鸟资料（名称和生日）、喂食提醒时间、语言、备份、安装分享和健康警示分类。设置名称后，App 里的问候、标题、喂食提示同步变化。
保留本地 JSON 备份、每日打卡、喂食确认、维基百科 API、繁简切换和免费 GitHub Pages。
本地储存 key 不变，不主动删除资料。纯网页在 iPhone PWA 关闭后不能后台定时推送；可导出 iPhone 日历提醒，或在提醒事项手动设置。
网站：https://b110212000.github.io/lovebird-guide/
