# 香蕉的养鸟手册（v2.1.0）

一个免费、纯静态的 iPhone PWA，支持简体中文和繁體中文。

## v2.1.0 新功能

- **喂食提醒 / 确认**：「打卡」页有早上和晚上两个可修改的检查时间（默认 08:00、18:00），每日单独记录是否检查／补充饲料，勾选时记录真正完成时间。首页也会显示当天完成进度。记录使用浏览器 localStorage，旧的清单与日记保留。
- **不需要后端的 iPhone 提醒**：App 打开时可以显示到点提醒；点击「导出 iPhone 每日提醒」下载每天重复的 `.ics` 日历事件及提醒。必须在手机上**确认导入并开启日历通知**，iOS 并不保证 Safari 直接打开 .ics 可导入。如无法导入，请在 iPhone「提醒事项」按页面列出的时间，手动建立每天重复提醒。**App 关闭后，仅靠纯静态 PWA 不能可靠地定时后台推送**。
- **安装及分享教程**：「更多」→「iPhone 安装教程与分享」，包含 Safari 分享→添加到主屏幕的操作步骤、App 使用步骤、系统分享、复制网站链接。
- **适用对象**：喂食打卡默认代表检查、补充已断奶健康小鸟的主食；并非每天只能喂两次。健康牡丹鹦鹉需要持续获得合适主食和饮水。未断奶幼鸟喂养请咨询鸟类兽医。
- **本地数据**：记录和提醒时间仅保存在目前设备的 localStorage（手机日历中的提醒则受用户的 iCloud/日历设置控制）。「打卡」页原本的 JSON 导出／导入备份会包含新的提醒设置及勾选记录，删 App 前先备份。
