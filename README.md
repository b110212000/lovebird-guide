# 香蕉的养鸟手册 🐤

**v2.0.0 | iPhone PWA App 风格大改版**

新设计：五栏底部导航（首页、指南、月龄、打卡、更多）、分页面切换、放大字体、卡片式首页、侧边目录、健康信息与简繁语言切换。保留原本的养护资料、维基百科 API、个人记录、JSON 备份/导入和原来的黄色牡丹鹦鹉 App 图标。

- 网站：https://b110212000.github.io/lovebird-guide/
- 默认简体中文，可切换繁体中文。
- iPhone：Safari → 分享 → 添加到主屏幕。
- 数据只存本机浏览器：换手机或删除 PWA 前，务必先在「打卡」页面导出备份。
- 纯静态 GitHub Pages，不需要付费 API、数据库或后端。
- `index.html` 包含 UI、内容与交互；`manifest.webmanifest` 和 `sw.js` 实现 PWA 与缓存；`icons/` 保存鸟图标。
- 只供科普，不代替鸟类兽医；幼鸟没有完全断奶前，不能按月龄擅自停奶。
